A multiplayer quiz game I'm building as a hobby project for my girlfriend's birthday, so she and her friends can play together.

## Features

- **Real-time multiplayer** using WebSockets to handle multiple concurrent connections.
- **Server-side game logic** to manage game state, teams, questions, and scoring.
- **Multiple round types**, including multiple choice, fastest buzzer, and real-life challenges.
- **Shared game experience** with players joining from their phones while the game is displayed on a larger screen.

## Status

Work in progress. The goal is to build a simple, fun multiplayer experience while learning more about Go, WebSockets, and real-time application design.
